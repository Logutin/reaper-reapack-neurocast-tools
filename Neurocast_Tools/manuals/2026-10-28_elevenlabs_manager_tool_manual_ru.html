ElevenLabs Manager · Рабочее руководство

Готово к проверке владельцем · исходник v0.2.3 · состояние на 28.10.2026. После обновления инструмента сведения могут устареть. Текстовая редакция от 11.11.2026: иллюстрации отложены по решению владельца; инструкции доступны без них. Новая проверка установленного Help остаётся отдельным шагом.

Назначение и короткий маршрут

ElevenLabs Manager управляет назначением общего ElevenLabs-аккаунта, индивидуальным балансом и доступом пользователей Neurocast. Он предназначен для менеджера с соответствующими правами. Для генерации речи, выбора/создания голосов и работы с аудио используется отдельный ElevenLabs Tool.

Интерфейс Manager остаётся английским. Русские пояснения ниже используют точные английские названия кнопок. Дорожки, айтемы и временной диапазон выбирать не требуется; инструмент не создаёт медиа и не изменяет проект REAPER. Его подтверждённые изменения относятся к серверным учётным данным пользователей и не отменяются через Undo REAPER.

Обычная работа
  1. Войдите в Neurocast через Settings → Login.
  2. Отдельно нажмите Connect Manager.
  3. В Users найдите нужного человека и проверьте его Email.
  4. При необходимости назначьте el_1 или el_2; для баланса/доступа откройте Open.
  5. Введите нужный итоговый баланс и состояние доступа, нажмите Save balance / access и проверьте подтверждение.
  6. Дождитесь чтения состояния и истории; сверяйте итог, а не только отправку запроса.
  7. По окончании нажмите Disconnect Manager.

К началу руководства

01 · Вход и подключение Manager

Запустите elevenlabs_manager_tool.lua из списка действий REAPER. Нужны Neurocast Tools с ReaImGui и вспомогательными файлами, выданная идентификация установки и учётная запись с разрешением управлять пользователями. Обычный пользовательский вход сам по себе не даёт права менеджера.

  1. Откройте Settings → Account / Credentials. Введите Email и Password, при необходимости включите Remember me, нажмите Login. Используются данные Neurocast; ключи ElevenLabs сюда не вводятся.
  2. Проверьте Active backend:: для обычной работы используется производственный сервер. Если ранее был включён режим разработки, до входа/подключения вернитесь через Use production.
  3. В разделе Manager connection нажмите Connect Manager. Успешное восстановление сохранённого входа не выполняет этот шаг автоматически.
  4. Дождитесь загрузки данных пользователей и аккаунтов. Сверьте сообщение подключения и время Expires:. Если данные ещё загружаются, дождитесь окончания запроса, не повторяя подключение.
У одного менеджера активно одно подключение: новый вход через Connect Manager заменяет его прежнее подключение в браузере или другом окне REAPER. Подключение действует 30 минут без автоматического продления. Обычное обновление входа не продлевает его. После истечения, замены или перезапуска сервера подключитесь явно.

Во время простоя состояние подключения проверяется примерно каждые 20 секунд; занятые запросы могут отложить проверку. Disconnect Manager завершает соединение Manager, но не является выходом из обычной сессии Neurocast. Для очистки сохранённого входа сначала отключите Manager, затем используйте Forget stored login.

Подключение и общие кредиты

Перед изменениями проверьте Manager connection и Expires. Shared account credits показывает общий счёт провайдера.

02 · Пользователь и назначение аккаунта

В Users нажмите Refresh users, если нужен свежий список. Filter ищет по имени, username и email; поиск локальный и не меняет данные. Esc очищает активное поле. Счётчик Users: найдено / всего позволяет отличить пустой результат фильтра от отсутствия загруженного справочника. Заголовки Name, Username, Email и Current позволяют менять сортировку.

Проверьте Email конкретной строки, особенно при одинаковых именах. Current показывает назначенный общий аккаунт или Unassigned. Колонка Balance / Access отдельно показывает баланс и On/Off. Это разные условия допуска к генерации.

ДействиеРезультат
el_1 / el_2Назначает пользователю соответствующий настроенный общий аккаунт. В подтверждении проверьте получателя и цель. Недоступный аккаунт выбрать нельзя; текущий вариант подсвечен и отключён.
UnassignСнимает назначение аккаунта после подтверждения. Баланс, отдельный флаг доступа и ожидающие списания сохраняются. Это не удаление пользователя и не обнуление его счёта.
OpenОткрывает подробности пользователя, редактор баланса/доступа и загружает первую страницу истории.

Для нового использования ElevenLabs одновременно нужны назначенный аккаунт, включённый доступ и положительный индивидуальный баланс. Один большой баланс без назначения или с отключённым доступом не разрешает работу. Переназначение не переносит старые ожидающие операции на новый аккаунт.

Поиск и назначения

Для назначения найдите нужного пользователя и проверьте Current. Действия el_1/el_2/Unassign меняют назначение; Open открывает детали.

03 · Баланс и доступ

  1. Нажмите Open в нужной строке. Ещё раз проверьте Selected user: и текущие Account, Balance, Access и Revision.
  2. В Balance (absolute) введите новое итоговое значение. Это замена, не прибавление. Например, при текущем 1000 ввод 200 означает итог 200; чтобы получить итог 1200, нужно ввести 1200 и проверить актуальное состояние перед сохранением.
  3. Access enabled разрешает или запрещает новые операции независимо от назначенного аккаунта. Можно изменить только этот флаг, оставив баланс прежним.
  4. Нажмите Save balance / access. В подтверждении сверьте пользователя, итоговый Balance и Access enabled. При ошибке выбора отмените диалог.
  5. Дождитесь автоматического чтения текущего состояния и истории. Успех отправки не заменяет сверку результата. При несовпадении ожидаемого значения не нажимайте сохранение повторно без разбора истории.

Числа вводите с точкой как десятичным разделителем, без разделителей тысяч. Допускаются положительные, нулевые и отрицательные значения, до девяти значащих знаков после запятой в пределах представимости. Нулевой или отрицательный баланс блокирует новые операции пользователя. Технический предел модуля значения — 9007199.25474099; это ограничение представления, а не рекомендация размера баланса. Не каждое дробное число внутри диапазона представимо: отвергнутое значение нужно исправить по сообщению.

Баланс не является банковским счётом или суммой в рублях: используйте единицы внутреннего учёта сервиса, согласованные в вашей работе. Не выводите индивидуальный баланс из общих кредитов ElevenLabs простым копированием.

Изменение баланса или доступа не обнуляет расход и не отменяет ожидающие списания. Позднее завершившаяся задача может снова изменить баланс. Сохранение проверяет Revision: при конфликте загружаются свежие значения, а прежняя запись не повторяется автоматически.
Редактор и подтверждение

Balance (absolute) задаёт итоговый баланс. Проверьте Access enabled и выбранного пользователя перед подтверждением Save balance/access.

04 · История, ожидание и общие кредиты

История и незавершённые операции пользователя

В Balance / access history доступны Refresh и, при наличии продолжения, Load more. История показывает изменение (Delta), остаток, изменение доступа, Revision, инициатора и время. Pending jobs содержит ожидающие задачи с исходным аккаунтом, операцией и причиной неопределённости. В верхней сводке Consumed: — накопленный расход, Pending: — число ожидающих задач, Uncertain: — число неопределённых.

Открытие истории и Pending ничего не отменяет и не завершает принудительно. Если ожидающая операция долго не меняется, передайте её безопасный идентификатор администратору. Не пытайтесь «исправить» неизвестное списание случайной правкой баланса.

Страницы отражают живое состояние, а не зафиксированный снимок на один момент. Используйте Refresh для нового просмотра, Load more — для продолжения текущего списка. Пустая страница или Not loaded после сбоя не доказывает отсутствие операций. Не суммируйте обновлённые и старые страницы как полный отчёт.

Кредиты общих аккаунтов

Shared account credits → Refresh credits запрашивает текущее состояние каждого общего аккаунта: Used, Allowance, Remaining, Reset и Checked. Общие цифры включают работу других приложений и не пополняют пользовательские балансы.

Сбой одного провайдера показывается отдельной строкой Unavailable; другой аккаунт может загрузиться успешно. Unavailable — отсутствие подтверждённого значения, не ноль. При указании Retry after дождитесь этого срока и обновите явно. Проверяйте Checked: старое число не является текущим обещанием доступного ресурса.

История и Pending

Историю операций используйте для проверки подтверждённых изменений. Состояние пользователя и общий счёт провайдера проверяйте отдельно.

05 · Ошибки и восстановление

СитуацияЧто делать
Обычный вход выполнен, но редактор недоступен.Нажмите Connect Manager и дождитесь загрузки. При отказе прав обратитесь к администратору; повтор ввода баланса права не меняет.
Подключение истекло или заменено.Согласуйте, какое окно будет рабочим. Нажмите Connect Manager явно. Не запускайте бесконечное переподключение нескольких окон, вытесняющих друг друга.
Ошибка рядом с балансом: Cannot save.Прочитайте причину. Исправьте числовой формат, точность или диапазон. Для неизменённых полей сохранять нечего. Сообщение не должно исчезать только из-за успешной фоновой проверки соединения.
Конфликт Revision или результат записи неизвестен.Сохранённое действие не отправляется повторно. Дождитесь чтения состояния и истории. Если показана блокировка, используйте Read current state and history; при потере соединения сначала явно подключитесь.
Чтение после записи снова не удалось.Оставьте окно открытым, восстановите соединение и повторите только Read current state and history. Дальнейшие записи остаются заблокированными до сверки. Не сменяйте сервер и не перезапускайте окно ради обхода блокировки.
Сервер отклонил точную арифметику, например CREDIT_ARITHMETIC_UNREPRESENTABLE.Это отказ без частичной правки. Сверьте текущие значения и историю, передайте безопасный код администратору. Не делите желаемую правку на случайные промежуточные записи.
Один общий аккаунт показывает Unavailable.Проверьте код и время проверки, дождитесь Retry after при наличии, затем Refresh credits. Не считайте баланс равным нулю и не переназначайте всех пользователей только из-за отсутствия ответа.

Кнопки могут быть временно отключены из-за текущего запроса, проверки результата, отсутствия подключения или уже выбранного назначения. Перезапуск не восстанавливает гарантированно контекст незавершённой правки: если окно уже закрыто, перед новой записью заново найдите пользователя и внимательно прочитайте его состояние и историю.

Ошибочно подтверждённая запись исправляется новой осознанной серверной правкой после сверки. История сохраняет прежнее действие. Не используйте Undo REAPER как способ отменить баланс или назначение.

Ошибка и чтение после неопределённого ответа

При истечении или замене Manager connection подключитесь явно. Неподтверждённую операцию сначала сверяйте с текущими данными.

06 · Настройки и помощь

Status window включает отдельное окно статуса. Request progress показывает этап, попытку, HTTP и ошибку запроса. Settings → Diagnostics содержит уровни журналирования и Copy log folder; журналы могут включать данные пользователей, поэтому перед передачей проверяйте их содержимое. Настройки Telemetry относятся к диагностике, не к учёту кредитов.

Use local development предназначена только для согласованной работы с тестовым сервером. При смене сервера теряется текущий рабочий контекст; это не средство восстановления после неопределённой правки. Сначала завершите сверку.

Help открывает это русское руководство без входа и независимо от блокировки серверных действий. Если HTML отсутствовал на старте, кнопка скрыта: восстановите руководство из комплекта и перезапустите скрипт. При ошибке открытия используйте путь из сообщения вручную. Интернет для чтения и печати не нужен; для чтения/изменения серверных данных нужен.
