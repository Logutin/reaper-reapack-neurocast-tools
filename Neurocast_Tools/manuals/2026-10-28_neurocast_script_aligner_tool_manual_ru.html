Neurocast Script Aligner · Рабочее руководство

Готово к проверке владельцем · исходник v0.1.1 · состояние на 28.10.2026. После обновления инструмента сведения могут устареть. Текстовая редакция от 11.11.2026: иллюстрации отложены по решению владельца; инструкции доступны без них. Новая проверка установленного Help остаётся отдельным шагом.

Назначение и короткий маршрут

Neurocast Script Aligner сопоставляет сценарий DOCX с аудио и переносит результат в текстовые айтемы REAPER по персонажам. Используйте его, когда нужен тайминг реплик по звучащему материалу. Это серверная обработка, для которой отправляются документ и выбранный фрагмент аудио. Сам инструмент не озвучивает текст и не заменяет исходную фонограмму.

Если документ уже содержит пригодные таймкоды и нужно только перенести реплики, используйте локальный DOCX Import. У Aligner нет такого же пошагового редактора столбцов и персонажей: документ должен быть заранее подготовлен для сервиса.

Обычная работа
  1. Сохраните проект и подготовьте DOCX, соответствующий аудио.
  2. Выделите ровно одну дорожку и нужный интервал времени.
  3. Войдите в Neurocast, откройте Script Aligner и нажмите Select DOCX.
  4. Проверьте параметры и нажмите Start script aligner.
  5. Дождитесь успешной обработки, скачивания и разбора JSON.
  6. Проверьте сводку и смещение, затем Import parsed JSON to project.
  7. Проверьте текст, дорожки и синхронность по звуку; при необходимости используйте Undo.

Большая часть текущего интерфейса остаётся английской даже при выборе русского языка. Ниже приведены точные подписи, а русское пояснение объясняет действие. %s и %d в подписях означают подставляемое значение и число.

К началу руководства

01 · Документ и аудио

  • Запустите neurocast_script_aligner_tool.lua из списка действий REAPER. Нужны Neurocast Tools с ReaImGui и вспомогательными файлами, выданная идентификация установки и учётная запись с доступом к Script Aligner.
  • Сохраните проект и проверьте запись во временную папку. Несохранённый проект блокирует элементы сценарного потока.
  • Подготовьте настоящий файл .docx с репликами, персонажами и исходным таймингом в формате, принятом вашим процессом работы с сервисом. Простое переименование .doc не конвертирует файл. Скрипт не предлагает выбор столбцов и не гарантирует поддержку произвольного Word-макета.
  • Проверьте, что документ соответствует выбранной версии фонограммы. Сопоставление текста другой редакции с аудио может дать пропуски и резервный тайминг.
  • Выделите ровно одну дорожку с нужным звуком и непустой временной интервал. Выделения айтемов недостаточно. Прослушайте интервал, проверьте Mute и FX: перед отправкой будет создан временный post-FX FLAC, то есть звук после обработки дорожки.

В Настройки (Settings) → Учетная запись / Учетные данные (Account / Credentials) введите Email и Password, при необходимости включите Remember me, затем Login. Load current user позволяет проверить, под какой учётной записью выполнен вход. Инструмент использует отдельный сервис Script Aligner; менять сервер для обычной работы не нужно.

Откройте Script Aligner, нажмите Select DOCX и проверьте Selected DOCX. Рядом должны быть указаны правильная исходная дорожка в Track mode source и Time selection. Путь должен вести к доступному документу, а не к перемещённому файлу.

Готовность к запуску

Перед Start script aligner проверьте DOCX, выбранную дорожку, временной диапазон и параметры.

К началу руководства

02 · Запуск и ожидание

  1. Для обычного первого прохода оставьте Match threshold (0-1) равным 0.65, Time window (sec) — 5, если ваша задача не требует других настроек.
  2. Нажмите Start script aligner один раз. Скрипт запоминает начало временного выделения, рендерит аудио, подготавливает и загружает DOCX и FLAC, затем создаёт серверную задачу.
  3. Следите за таблицей запросов и состоянием Run. Различайте отправку файлов, создание задачи, ожидание результата и скачивание. Во время опроса виден отсчёт до следующей проверки.
  4. После успешной задачи запоминается Last successful job id, результат JSON автоматически скачивается и разбирается. Готовый JSON ещё не вставлен в проект.
  5. Оставайтесь в исходном проекте и держите окно открытым до проверки и импорта. Не запускайте второй проход только потому, что первый выполняется долго.
Потерянный ответ при создании задачи опасен повтором. У текущего инструмента есть общий механизм повторов, который может повторно создать уже принятую сервером задачу. Даже автоматический повтор не гарантированно безопасен. При неопределённом исходе создания проверьте существующие задания в Studio с администратором до ручного Retry или нового запуска. Этот недостаток в данной версии не исправлен.

Stop polling останавливает только локальный опрос. Серверное задание этим не отменяется. Отдельной обычной кнопки возобновления опроса нет; не нажимайте Start script aligner как замену «продолжить». Если успешный результат ещё не был запомнен, сначала выясните его состояние в Studio.

Обработка и опрос

Во время обработки следите за этапами, состоянием Run и временем следующего опроса.

03 · JSON и импорт

Путь показан в Last downloaded JSON. Проверьте сводку числа строк, строк с исправленным таймингом, резервным таймингом, проблемами исправленного времени и неиспользованными сегментами. Statuses показывает распределение серверных статусов. Успешный разбор означает пригодность структуры JSON, а не точное совпадение каждой реплики с аудио.

При сохранённом успешном задании Download result JSON повторно получает его результат. Re-parse downloaded JSON заново разбирает уже скачанный локальный файл; она не запускает серверную обработку. После перезапуска окна эти кнопки не являются универсальным загрузчиком любого старого JSON: для импорта нужен сохранённый в этой сессии контекст.

Проверьте положение во времени

Обычная формула позиции: начало выделения при запуске + время строки результата + дополнительное смещение импорта. Текущая позиция курсора и новое выделение не заменяют сохранённое начало. В Track-mode import base offset проверьте исходную базу. При включённом дополнительном смещении итог показан в Resolved import base offset.

Например, начало выбранного фрагмента было 10:00, реплика в результате начинается через 12 секунд, дополнительное смещение выключено — ожидайте айтем на 10:12. Если весь результат действительно нужно сдвинуть на минуту вправо, включите соответствующее смещение: позиция станет 11:12. Это только пример расчёта, не рекомендуемая поправка для каждого проекта.

Выполните импорт

  1. Убедитесь, что открыт исходный проект, сводка понятна и смещение верно.
  2. Нажмите Import parsed JSON to project. Для персонажа используется первая существующая дорожка с точно совпадающим именем; если её нет, создаётся новая в конце проекта. При одинаковых именах заранее проверьте, какая дорожка будет первой.
  3. Реплики появляются как текстовые айтемы; текст хранится в заметках. Серверное исправленное время используется, когда оно корректно. Иначе применяется резервная позиция/длительность; оценка длины опирается на 20 символов в секунду с минимумом 1 секунду. Такие реплики особенно требуют ручной проверки.
  4. Проверьте сообщение Last import, дорожки, заметки, цвета и предупреждающие маркеры. Прослушайте несколько совпавших и все проблемные участки.

Импорт добавляет айтемы и при необходимости маркеры/дорожки. Он не заменяет ранее импортированный набор автоматически. Повторное нажатие может добавить дубли. Для пересмотра смещения сначала отмените предыдущий импорт через Undo REAPER, затем повторите его. Undo не отменяет серверное задание и не удаляет скачанный JSON.

Сводка и смещение перед импортом

Перед Import проверьте parsed/corrected/fallback и итоговое смещение. После изменения параметров разбора используйте Re-parse.

Результат в проекте

После импорта проверьте текстовые айтемы на дорожках персонажей, заметки реплик и совпадение с исходным аудио.

04 · Параметры и смещение

ЭлементКак использовать
Match threshold (0-1)Порог уверенности сопоставления, 0–1, исходное значение 0.65. Это параметр следующего серверного запуска. Не считайте его процентом гарантированно правильных реплик.
Time window (sec)Окно времени 1–60 секунд, исходное значение 5. Меняйте осмысленно для задачи и оценивайте результат. Это не сдвиг всех айтемов.
Enable import offsetВключает дополнительный локальный сдвиг при импорте. Он не требует повторной серверной обработки.
Offset direction, Left, RightВлево вычитает величину смещения, вправо прибавляет её. Проверяйте итоговую базу перед вставкой.
Offset hours:, Offset minutes:Размер сдвига в часах и минутах. Отдельного поля секунд здесь нет. Не задавайте сдвиг, уводящий реплики раньше начала проекта.

Порог CSV в интерфейсе не задаётся: используется серверное значение по умолчанию. Руководство не обещает конкретную схему произвольного DOCX или качество результата при изменении параметров: это следует проверять на подготовленном материале.

05 · Ошибки и ограничения

СитуацияЧто делать
Запуск недоступен.Проверьте сохранённый проект, вход, выбранный DOCX, ровно одну дорожку и ненулевое временное выделение. Завершите текущий запрос. Refresh checks в настройках повторяет проверку локальных условий.
Файл не готов к загрузке или локальный рендер не создан.Проверьте путь к DOCX, доступность исходного аудио, свободное место, права временной папки и состояние дорожки. Ошибка подготовки не означает, что виноват формат документа: прочитайте конкретную причину.
Сбой опроса или скачивания.Оставьте окно открытым, восстановите сеть, прочитайте строку запроса. Опрос может запланировать следующую попытку; ручная Retry относится к конкретной строке. Для уже успешной задачи доступна Download result JSON. Не повторяйте создание вместо скачивания.
Сбой создания с неизвестным результатом.Не используйте Retry до проверки в Studio. Сервер мог принять первый запрос, а повтор создаст дубликат. Передайте администратору безопасный текст ошибки и видимый идентификатор, если он есть.
Result parse failed или много fallback.При ошибке скачивания заново получите JSON успешной задачи; для существующего файла используйте Re-parse downloaded JSON. При корректном разборе и плохом совпадении проверьте редакцию сценария, исходное аудио и тайминг. Не импортируйте вслепую.
Нет сохранённого начала выделения.Импорт требует контекст этой сессии. Новый курсор не восстанавливает его автоматически. Не обходите сообщение случайным сдвигом; согласуйте восстановление результата с поддержкой.
Импорт завершился ошибкой.Осмотрите проект: часть айтемов могла быть добавлена до ошибки. Используйте Undo для отмены частичного импорта, исправьте причину, затем повторите. Отрицательная позиция после сдвига недопустима.

Clear request table and reset state очищает локальное состояние, выбранный документ и контекст результата; это не отмена работы на сервере и не Undo импорта. Используйте её после сохранения нужных данных. Не закрывайте окно и не сбрасывайте состояние как первый способ лечения сетевой ошибки.

Рабочий успешный путь ранее подтверждён владельцем. Безопасный повтор неоднозначного создания, восстановление после закрытия, полный набор плохих соединений и все платформы не квалифицированы.

06 · Настройки и помощь

Language меняет язык, Окно статуса (Status window) включает отдельное окно статуса. Настройки (Settings) содержит учётную запись, пути, Диагностика (Diagnostics) и Телеметрия (Telemetry). Forget stored login (and logout) очищает сохранённый вход и выполняет выход; это не способ отменить серверную обработку.

Details помогает найти этап и причину. Передавайте поддержке версию, этап, понятную ошибку и идентификатор задачи, а не полные технические ответы с адресами загрузки или данными учётной записи.

Помощь (Help) открывает этот локальный HTML без входа в сервис. При отсутствии файла на старте кнопка скрывается; восстановите руководство из комплекта и перезапустите инструмент. При ошибке открытия используйте показанный путь вручную. Чтение и печать работают без интернета; запуск Aligner требует сети.

После обновления скрипта сведения могут устареть. Если версия или подписи отличаются, сверьте руководство с вашей установкой. Иллюстрации будут добавлены отдельно; все основные действия уже описаны текстом. Файл можно читать без подключения к интернету.
